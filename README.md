# Freak Legends (frontend)

Next.js + React + TypeScript skeleton.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Dokumenty prawne

`/cookies`, `/privacy` i `/terms` to szablony z polami `[w nawiasach]` — do weryfikacji przez prawnika. Nie uzupełniaj tych pól w kodzie.
