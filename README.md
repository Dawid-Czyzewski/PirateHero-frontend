# PirateHero Frontend

Frontend of the PirateHero game — a browser pirate-themed RPG. It includes the public layer and the in-game panel after login.

## Scope

- home page
- registration and login
- contact and informational pages
- game panel (character, missions, fights, dungeons, shop, ranking)
- communication with the backend REST API
- bilingual support (PL / EN)
- tests (Vitest, Playwright)

## Technologies

- React 19
- TypeScript
- Vite
- Tailwind CSS
- React Router
- TanStack Query
- i18next / react-i18next
- Vitest
- Playwright
